# GLIDE-SPEC 40 제조사 후보 1차 조사

- 조사일: 2026-09-14
- 목적: GLIDE-SPEC 40의 실제 제조 가능성이 있는 국내 OEM/ODM 후보를 1차로 좁히고 동일 RFQ를 보낼 대상을 선정한다.
- 제품 기준: 20 g 고체 스틱형 피부 마찰 감소 제품. 왁스/오일/실리콘 기반 고체 매트릭스에 미세 분말을 분산시키는 제형을 전제로 한다.

## 판단 원칙

1. '스틱을 만든다'는 사실만으로 적합 판정하지 않는다.
2. 선스틱/멀티밤/립밤/프라이머/블러 등 고체 스틱 경험은 기술적 유사성의 근거로만 사용한다.
3. 파우더 분산, 응집, 충진, 경도, 저온/고온 안정성은 실제 상담과 샘플로 확인한다.
4. 공개 MOQ는 참고값일 뿐 GLIDE-SPEC 40의 확정 MOQ로 간주하지 않는다.
5. 플랫폼/매칭 업체와 실제 제조공장을 구분한다.
6. 공개자료에서 확인되지 않은 항목은 '미확인'으로 남긴다.

## 2차/보조 채널

### 플랫폼/매칭 채널

- 화재(HWAJAE): 제조사를 직접 생산하는 곳으로 분류하지 않고, 소량 제조사 매칭/탐색 채널로 활용.
- 셀프코스(Selfcos): 제조공장 탐색 및 문의 채널로 활용. 실제 제조사는 개별 확인 필요.
- 서울코스랩(SeoulCosLab): OEM/ODM 연결·조율 성격이 강하므로 실제 제조공장과 계약 구조를 확인한 뒤 사용.

플랫폼은 제조사 후보 수를 늘리는 용도로 쓰고, 최종 후보 평가표에서는 실제 생산공장과 분리한다.

## 조사상 주의사항

- 라온하제와 헤이브랩의 300개 MOQ는 각 회사가 공개한 일반적인 소량 생산 조건이며, GLIDE-SPEC 40에 그대로 적용된다는 뜻이 아니다.
- 한국화장품제조, 한국콜마, 코스맥스처럼 스틱 기술력이 확인되는 대형 업체는 소량 생산 가능성을 공개자료만으로 판단하지 않는다.
- 한폼은 립밤 스틱의 Hot Filling 및 전용 충진 설비 경험이 확인되지만 기본 MOQ 5,000개를 명시하므로 현재의 1,000~3,000개 초도 전략과는 충돌할 수 있다.
- '파우더인밤 스틱'이라는 이름을 제조사 검색어로 고정하지 않는다. 제조사에는 '20 g 고체 스틱형 피부 마찰 감소 제품 + 미세 분말 분산 + 비교적 건조한 표면감'으로 설명한다.

## 다음 단계

1. 최우선 6개 업체에 동일 RFQ 발송.
2. 회신 내용을 동일한 표에 기록.
3. MOQ/가격보다 먼저 '이 제형을 실제로 만들 수 있는가'를 판정.
4. 기술적으로 가능한 3개를 선정.
5. 2~3개 업체에서 샘플 또는 Pilot 제작.
6. Glide, 잔여감, 건조감, 마찰감, Transfer, 지속성, 경도, Pay-off를 동일 조건으로 비교.
7. 최종 제조사 1~2개 선정.
