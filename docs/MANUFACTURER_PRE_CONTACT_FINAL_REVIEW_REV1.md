# GLIDE-SPEC 40 — Manufacturer Pre-Contact Final Review

- 작성일: 2026-09-15
- 상태: CURRENT / Pre-Contact Gate
- 목적: 6개 제조사 1차 문의 직전의 구조·후보·정보공개 범위를 최종 확정한다.

## 1. 최종 판단

현재 6개 제조사 선정은 유지한다.

1. 라온하제
2. 헤이브랩
3. 한국화장품제조
4. 모나미코스메틱
5. 엠엘에스(MLS)
6. 코스모C&T

현재 단계에서는 6개사에 서로 다른 상세 기술질문을 보내지 않는다.

**Phase A는 동일한 1차 RFQ로 통일하고, 회사별 차이는 Phase C 기술상담에서 적용한다.**

## 2. 제조사 선정 구조

```text
Phase A — 6개사 동일 1차 RFQ
        ↓
Phase B — 응답 정규화/비교
        ↓
2~3개 기술 후보 압축
        ↓
Phase C — 회사별 기술 질문 + 샘플 개발
        ↓
실제 샘플 비교
        ↓
필요시 수정 개발
        ↓
최종 제조 파트너 선정
        ↓
Phase D — NDA / IP / 계약
```

1차 문의의 목적은 '최고의 제조사'를 고르는 것이 아니라 **상담하고 샘플을 만들어볼 가치가 있는 제조사인지 확인하는 것**이다.

## 3. 1차 문의에서 공개할 정보

공개 범위:

- 20 g 전후 고형 스틱형 피부 마찰 감소 제품
- 피부 마찰이 큰 부위에서 사용하는 제품
- 왁스/오일/실리콘 계열 고형 베이스 방향
- 미세 분말의 균일 분산 필요
- 부드러운 발림
- 비교적 건조한 사용감
- 낮은 끈적임
- 땀/반복 마찰/의류 접촉을 고려한 사용성
- 초기 개발 단계이며 제조사의 formulation 및 공정 개발 역량을 함께 검토한다는 점

공개하지 않을 정보:

- Rev.7.3 전체 상세 처방
- P001 상세 처방 및 실행 조건
- GLIDE Simulator 내부 구조
- 모델/알고리즘
- 내부 DOE 및 EIG 계산
- 내부 qualification 기준의 세부 구현

Rev.7.3은 제조사와 기술개발 단계에서 필요 범위에 한해 공개·협의한다.

## 4. 1차 RFQ 필수 확인 항목

1. 20 g 전후 고형 스틱 개발/생산 가능 여부
2. 자체 formulation 개발 및 샘플 제작 가능 여부
3. 유사 스틱 제형의 실제 개발/생산 경험
4. 최초 샘플 개발 비용
5. 샘플 개발 기간
6. 샘플 수정/추가 개발 비용 및 일반적인 절차
7. MOQ
8. MOQ 기준 대략적인 단가
9. 500 / 1,000 / 3,000개 수준의 테스트·초도 생산 가능 여부
10. 개발부터 양산까지의 연속 진행 가능 여부
11. 상담/미팅 가능 여부 및 일반적인 진행 절차

가능한 경우 추가로 확인:

- 내용물 MOQ와 패키지 MOQ의 차이
- 개발비의 양산 시 상계 여부
- QC/안정성 시험의 기본 범위

## 5. 표준 1차 문의문

> 안녕하세요.
>
> 20g 정도의 고형 스틱 형태 스킨케어 제품을 개발·제조하고 있어 문의드립니다.
>
> 제품은 피부 마찰을 줄이는 용도의 스틱으로, 왁스/오일/실리콘 계열의 고형 베이스에 미세 분체가 균일하게 분산되는 형태를 생각하고 있습니다.
>
> 원하는 방향은 부드럽게 발리고, 사용 후 비교적 보송한 느낌이 남으면서 반복적인 마찰과 땀, 의류 접촉에도 형태와 사용감이 유지되는 제품입니다.
>
> 현재 초기 개발 단계라 제조사의 처방 개발 역량과 샘플 개발 가능 여부부터 상담받고 싶습니다.
>
> 아래 사항을 확인 부탁드립니다.
>
> 1. 해당 형태의 고형 스틱 제품 개발이 가능한지
> 2. 제조사에서 처방 개발 및 샘플 제작까지 가능한지
> 3. 유사한 스틱 제형의 개발·생산 경험이 있는지
> 4. 최초 샘플 개발 비용과 대략적인 기간
> 5. 샘플 수정/추가 개발 비용 및 일반적인 개발 절차
> 6. 생산 가능한 최소 수량(MOQ)
> 7. MOQ 및 500 / 1,000 / 3,000개 정도 기준의 대략적인 예상 단가
> 8. 개발 후 동일 제조사에서 양산까지 진행 가능한지
> 9. 상담 또는 미팅이 가능한지
>
> 아직 최종 처방이나 패키지는 확정하지 않은 단계이며, 제품 방향과 목표 사용감을 기준으로 제조사와 함께 제형을 구체화하고자 합니다.
>
> 가능하시다면 상담에 필요한 자료와 진행 절차도 함께 안내 부탁드립니다.
>
> 감사합니다.

## 6. Phase B 비교 기준

1차 답변은 동일 기준으로 정규화한다.

| 평가항목 | 배점 |
|---|---:|
| 고형 스틱 개발 가능성 | 15 |
| 자체 formulation 역량 | 15 |
| 유사 스틱 경험 | 15 |
| 분체 분산 경험 | 10 |
| 샘플 개발 대응 | 10 |
| Pilot/MOQ 대응 | 10 |
| 예상 원가 | 10 |
| 개발→양산 연속성 | 5 |
| 리드타임 | 5 |
| 커뮤니케이션/응답 품질 | 5 |
| 합계 | 100 |

홈페이지에 '스틱 가능'이라고 적혀 있다는 사실만으로 높은 점수를 부여하지 않는다. 구체적인 개발 경험, 조건, 질문에 대한 답변의 질을 우선한다.

## 7. Phase C 회사별 검증 방향

### 라온하제
- 소량 스틱의 실제 제조 경험
- 분체 함유 고형 스틱 경험
- 분체 침강/응집
- 냉각 및 표면 bloom
- 20 g 용기 대응
- 500/1,000/3,000개 실제 조건

### 헤이브랩
- 소량 샘플/파일럿의 실제 대응 범위
- 고형 스틱 제조 라인
- 분체 분산 경험
- 샘플 수정 횟수와 비용 조건
- 샘플→양산 동일 공정/라인 여부

### 한국화장품제조
- 선스틱/멀티스틱과 GLIDE 제형의 기술적 차이
- 무수 고형 제형 및 분체 함유 제형 대응
- 경도와 Pay-off 조절
- 충진/냉각 조건과 scale-up
- 자체 R&D의 formulation 제안 범위

### 모나미코스메틱
- 비자외선 목적의 스틱 개발 경험
- 파우더/피그먼트 분산
- 경도/Pay-off/피니시 조절
- 20 g 패키지 대응
- 내용물과 용기의 동시 최적화

### MLS
- 현재 스틱 생산 가능 여부
- 현재 MOQ 및 pilot 대응
- 자체 formulation 개발 범위
- 최근 유사 제품 경험

### 코스모C&T
- 선스틱 경험의 실제 범위
- 자체 고형 스틱 formulation capability
- 분체 분산
- pilot 규모
- 샘플→양산 연속성

## 8. GLIDE 모델 검증과 제조사 개발의 분리

제조사 샘플 개발 수와 GLIDE 물리 검증 실험 수를 동일하게 취급하지 않는다.

```text
제조사 Track:
6개사 → 2~3개사 → 샘플 개발 → 제조사 비교

GLIDE Validation Track:
P001 prediction snapshot → P001 실제 제조/측정 → residual/uncertainty → 다음 실험 결정
```

제조사 샘플은 측정조건, 원료/공정 추적성, 데이터 독립성이 확보된 경우에만 외부 검증 데이터로 활용할 수 있다.

## 9. 현재 실행 금지사항

- 6개사에 상세 Rev.7.3 처방을 일괄 공개하지 않는다.
- 첫 문의부터 기술 Audit 수준의 질문을 하지 않는다.
- 제조사 응답 전에 2~3개사 샘플 개발을 확정하지 않는다.
- 제조사 샘플을 P001 실측값으로 간주하지 않는다.
- P001~P018 전체 물리실험을 제조사 선정과 함께 확정하지 않는다.
- 제조사 규모/유명세만으로 우선순위를 결정하지 않는다.

## 10. 다음 실행

1. 본 문서를 현재 제조사 Pre-Contact 기준선으로 사용한다.
2. 6개사에 동일한 1차 RFQ를 보낸다.
3. 회신 원문과 연락일/담당자/조건을 기록한다.
4. 응답을 동일 평가표로 정규화한다.
5. 2~3개 기술 후보를 선정한다.
6. 후보별 Phase C 기술 질문을 적용한다.
7. 샘플 개발 조건을 비교한 뒤 실제 샘플 제작을 결정한다.
