# GLIDE-SPEC 40 — Manufacturer First-Contact Protocol
## Rev.1.0

### 목적
신규 화장품 제조사/ODM 업체에 대한 **1차 문의를 과도하게 기술감사화하지 않고**, 실제 상담·샘플 개발로 이어질 가능성을 빠르게 확인한다.

> **핵심 원칙:** 1차 문의와 기술실사(Audit), NDA/IP 검토를 분리한다.

---

## 1. 1차 문의 원칙

첫 연락에서 제조사의 내부 연구자료, 상세 처방, 공정조건, 고객사 정보, 특허/IP 세부사항 등을 대량으로 요구하지 않는다.

1차 단계의 목적은 **"이 업체와 우리 제품을 개발할 수 있는가?"**를 확인하는 것이다.

### 1차 필수 확인 항목 — 7개

1. **개발 가능 여부** — 제품 컨셉에 맞는 ODM/OEM 개발 가능 여부
2. **샘플 개발 가능 여부 및 비용**
3. **대략적인 개발 기간**
4. **MOQ(최소 생산수량)**
5. **MOQ 기준 대략적인 단가 범위**
6. **개발부터 양산까지 진행 가능 여부**
7. **상담/미팅 가능 여부 및 일반적인 진행 절차**

---

## 2. 1차 문의 시 제공할 정보

제조사에는 제품의 핵심 컨셉과 요구사항을 **1페이지 수준**으로 전달한다.

- 제품 유형
- 사용 목적
- 목표 사용감/성능
- 예상 용량
- 목표 가격대 또는 목표 제조원가(공개 가능한 범위)
- 예상 출시 일정
- 특수하게 요구되는 사항

초기 단계에서는 상세 처방이나 내부 GLIDE-SPEC 40 모델/알고리즘을 모두 공개할 필요가 없다.

---

## 3. 표준 1차 문의문

> 안녕하세요.
>
> 신규 화장품 브랜드 제품 개발을 준비하고 있어 ODM/OEM 생산 관련하여 문의드립니다.
>
> 현재 제품 컨셉과 기본적인 요구사항을 정리하고 있으며, 아래 사항을 우선 확인하고 싶습니다.
>
> 1. 해당 컨셉의 제품 개발 가능 여부
> 2. 샘플 개발 가능 여부 및 대략적인 개발 기간
> 3. 최소 생산수량(MOQ)
> 4. MOQ 기준 대략적인 제품 단가 범위
> 5. 개발비 및 샘플 비용
> 6. 제품 개발부터 양산까지 진행 가능한지
> 7. 상담 또는 미팅 가능 여부
>
> 구체적인 처방 및 원료 조건은 상담 과정에서 제품 컨셉을 설명드린 후 협의하고자 합니다.
>
> 가능하시다면 신규 브랜드의 초기 제품 개발 과정과 일반적인 진행 절차도 함께 안내 부탁드립니다.
>
> 감사합니다.

---

## 4. 단계 분리

### Phase A — First Contact

위 7개 항목만 확인한다.

**목표:** 상담/샘플 후보 선별

### Phase B — Manufacturer Comparison

1차 답변을 바탕으로 업체별로 다음을 비교한다.

- 개발 가능성
- MOQ
- 예상 단가
- 개발기간
- 샘플 대응
- 상담 대응력
- 생산까지의 연결성

**목표:** 실제 상담할 후보 압축

### Phase C — Technical Development

실제 샘플 개발을 시작할 업체에만 상세 기술 질문을 진행한다.

- 제형 개발 방식
- 원료 선정
- 안정성
- QC
- pilot/scale-up
- 시험/검증
- 데이터 공유

### Phase D — NDA / IP / Contract

최종 후보에 한해 필요 범위에서 검토한다.

- 처방 권리
- 공동개발 결과물
- 독점권
- 원료/IP
- 데이터 사용권
- 계약 종료 후 권리

---

## 5. GLIDE-SPEC 40 내부 평가 원칙

제조사의 규모나 유명세만으로 평가하지 않는다.

**Manufacturer name → quality 보증**이라는 판단을 금지하고, 실제 샘플·시험·협업 과정에서 capability를 확인한다.

또한 **"제조사 80% / 브랜드 20%"와 같은 정량적 기여도 주장을 사용하지 않는다.** 제품마다 브랜드, ODM, 원료사, 시험기관의 개발 기여가 다를 수 있기 때문이다.

---

## 6. 이후 기술평가의 방향

상세 제조사 Audit은 필요하지만 **첫 문의 단계에서는 사용하지 않는다.**

후속 평가에서는 다음 capability를 검토할 수 있다.

- R&D / Formula
- Raw Material
- Manufacturing Process
- QC / Stability
- Efficacy testing support
- IP / Formula ownership
- MOQ / Cost / Lead time
- GLIDE-SPEC 40 데이터 협업

### 데이터 협업 목표

장기적으로는 제조사와의 실제 개발 데이터를 다음 루프로 연결하는 것을 목표로 한다.

`GLIDE-SPEC prediction → prototype → physical test → prediction/error comparison → model update`

단, 실제 제조사와의 데이터 공유 가능성이 확인되기 전까지 이를 1차 문의 조건으로 강제하지 않는다.

---

## 7. Decision Rule

**현재 단계에서는 "최고의 제조사"를 찾는 것이 아니라 "상담하고 샘플을 만들어볼 가치가 있는 제조사"를 찾는다.**

따라서 1차 문의는 짧게 유지하고, 실제 관심과 개발 가능성이 확인된 업체에만 다음 단계의 기술·IP 질문을 확장한다.
