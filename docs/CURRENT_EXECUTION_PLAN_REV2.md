# GLIDE-SPEC 40 Current Execution Plan Rev.2

작성일: 2026-09-15  
상태: CURRENT / 실행 기준선

## 0. 이 문서의 우선순위

이 문서는 과거 DOE/Physical Pilot 계획과 현재 실행 결정을 구분하기 위한 **현재 실행 기준선**이다.

현재 계획과 과거 문서가 충돌할 경우 이 문서를 우선한다. 과거 문서는 삭제하지 않고 변경 이력을 유지한다.

---

## 1. 핵심 개발 목표

GLIDE-SPEC 40의 목표는 대규모 실험을 먼저 수행하는 것이 아니다.

**공개 데이터와 가상 시뮬레이션으로 후보를 최대한 좁힌 뒤, 실제 제조·측정을 최소화하고, 실측값으로 모델을 검증·개선하는 것**이다.

기본 흐름:

```text
공개 데이터
   ↓
GLIDE Simulator / Virtual Screening
   ↓
후보 압축
   ↓
최소 실제 제조·측정
   ↓
예측값 vs 실측값
   ↓
오차 / 불확실성 분석
   ↓
모델 개선
   ↓
순차적 Active Learning
   ↓
필요한 경우에만 추가 실험
```

## 2. 제품 및 사업 기준선

현재 개발 제품은 **20 g 전후의 고형 스틱형 마찰 저감 제품**이다.

핵심 목표 사용환경:

- 러닝
- 행군
- 장시간 보행
- 피부 마찰이 큰 부위
- 땀/고온 환경
- 휴대 사용

목표 사용 특성:

- 마찰 저감
- 비교적 건조한 사용감
- 낮은 끈적임
- 적절한 전이 제어
- 안정적인 고형 스틱 구조

### 가격 가설

현재 사업성 검토 기준 소비자가는 **약 15,000원**으로 둔다.

목표 COGS는 **약 3,000원/unit**을 가설로 둘 수 있으나, 이는 검증된 제조원가가 아니다.

실제 가격은 다음 순서로 결정한다.

```text
목표 판매가
   ↓
제조사 실제 견적
   ↓
내용물 + 용기 + 포장 + 물류 + 수수료 + 마케팅 비용
   ↓
실제 단위경제성
   ↓
최종 판매가격
```

15,000원은 현재 목표 가격이지 최종 확정 가격이 아니다.

## 3. 제조사 역할의 원칙

GLIDE는 단순히 **"우리 처방을 그대로 생산해 달라"**는 제조 아웃소싱 모델로 접근하지 않는다.

제조사는 **제형개발 및 제조·공정 개발 파트너**로 본다.

### 역할 분담

**GLIDE가 제시하는 것**

- 제품 컨셉
- 목표 사용환경
- 목표 성능
- 핵심 평가항목
- 제품 형식
- 주요 제약조건
- 내부 개발 기준선(Rev.7.3)

**제조사가 제안하는 것**

- 제형 구조
- 원료 및 Grade 선택
- 세부 배합비
- 제조공정
- 공정조건
- 샘플 개발
- 양산성 및 원가 개선안

제조사가 GLIDE의 내부 기준선보다 더 적합한 처방이나 공정을 제안할 수 있다. 이를 배제하지 않는다.

단, 변경 사항은 반드시 기록하고 비교 가능하게 관리한다.

## 4. 제조사 RFQ 전략

현재 후보 제조사는 다음 6개사다.

1. MLS
2. 한국화장품제조
3. 모나미코스메틱
4. 라온하제
5. 헤이브랩
6. 코스모C&T

처음부터 6개 업체에 상세 처방을 제공하거나 개발비를 지출하지 않는다.

### 1차 RFQ

목적은 **제조사 선정이 아니라 기술적 적합성과 개발조건 비교**다.

확인 항목:

- 20 g 전후 고형 스틱 개발/생산 가능 여부
- 무수/oil/wax/silicone 계열 경험
- 미세 분말 분산 경험
- 유사 제형 개발/생산 사례
- 제형개발 방식
- 샘플 개발 가능 여부
- 최초 샘플 비용
- 수정 개발 비용
- 개발비의 양산 시 상계 여부
- 개발 일정
- MOQ 및 샘플 배치 규모
- 500~1,000개 테스트 생산 가능 여부
- 내용물 MOQ와 패키지 MOQ
- QC/안정성 시험 범위
- 처방 소유권 및 IP 조건
- 양산 공정 및 scale-up 지원

첫 RFQ에서는 Rev.7.3의 전체 세부 처방을 공개하지 않는다.

### 후보 압축

```text
6개 업체 RFQ
   ↓
2~3개 기술 후보
   ↓
2~3개 업체 샘플 개발
   ↓
실제 샘플 비교
   ↓
필요한 경우 수정 개발
   ↓
최종 제조 파트너 선정
```

샘플 개발비는 무료라고 가정하지 않는다. 업체별 조건을 비교한다.

## 5. 제조사 샘플과 GLIDE 모델 검증의 분리

제조사 샘플 개발 수와 GLIDE 모델의 독립 검증 실험 수는 같은 숫자가 아니다.

제조사 샘플은 **제품 개발·제조사 비교 목적**으로 사용한다.

측정조건, 원료/공정 추적성, 데이터 독립성이 확보된 경우에만 GLIDE의 외부 검증 데이터로 활용할 수 있다.

따라서 제조사 2~3개에서 샘플을 개발한다고 해서 GLIDE의 물리 검증 실험을 2~3개 또는 18개로 자동 확대하지 않는다.

---

## 6. Rev.7.3의 위치

Rev.7.3은 **GLIDE 내부 개발 기준선(Target Active Formula)**이다.

최종 생산 Formula로 고정하지 않는다.

제조사가 목표 물성을 만족시키기 위해 원료 Grade, 세부 배합비, 공정조건 등을 변경·개선할 수 있다.

변경 시 다음을 기록한다.

- 변경 항목
- 변경 이유
- 기대 효과
- 실제 결과
- Formula version
- Process version
- Data version

즉, 최종 제품 처방은 **Rev.7.3을 그대로 생산하는 것으로 미리 결정하지 않는다.**

## 7. 실제 GLIDE 모델 검증 실험

### 현재 결정

**처음부터 P001~P018 전체를 제조하지 않는다.**

첫 실제 GLIDE 검증은 **GS40-P001 1개 후보**만 제조한다.

P001~P018은 가상 DOE/후보군 및 과거 DOE 설계상의 식별자로 유지할 수 있으나, 실제 제조 일정이나 실제 Qualification 데이터셋을 의미하지 않는다.

```text
Virtual candidates
   ↓
GS40-P001 실제 제조/측정
   ↓
prediction vs actual
   ↓
오차 / 불확실성 분석
   ↓
EIG 재계산
   ↓
두 번째 실험이 필요한지 판단
```

과거 문서의 **18-run batch manufacture / n ≥ 16 physical pilot**은 현재 즉시 실행할 제조계획이 아니다.

### P002의 지위

과거 Rev.8에서 EIG Top-1이었던 `GS40-P002` 기록은 역사적 정보로 보존한다.

현재 첫 실제 실행은 P001이다.

P001 실측값 확보 후 전체 후보의 EIG/불확실성을 다시 계산해 다음 실험을 결정한다.

---

## 8. 초기 상업 생산량

**3,000개를 최소 생산량으로 고정하지 않는다.**

현재 검토 범위는 약 **1,000~3,000개**다.

500개 생산이 가능한 업체가 있다면 기술적·경제적 조건을 별도로 비교한다.

제조사 RFQ에서 가능하면 다음 수량별 단가를 받는다.

- 500개
- 1,000개
- 3,000개
- 10,000개

첫 상업 생산량은 샘플 결과, MOQ, 패키지 MOQ, 실제 원가, 예상 판매량을 보고 결정한다.

---

## 9. 규제의 위치

현재 단계에서는 대형 Regulatory Engine을 구축하지 않는다.

최소한의 **Regulatory Pre-screen**만 적용한다.

```text
원료/처방 후보
   ↓
Regulatory Pre-screen
   ↓
PASS / REVIEW / FAIL / UNKNOWN
```

검토 항목:

- 금지/제한 원료
- 사용 한도
- 기능성화장품/특수 분류 가능성
- Claim 근거 필요 여부
- 시장별 추가 검토 필요 여부

GLIDE가 최종 안전성·인증·법적 적합성을 자동 선언하지 않는다.

---

## 10. PX의 위치

PX/국군복지단은 **현재 제품 개발의 핵심 의사결정 기준으로 사용하지 않는다.**

향후 별도 유통채널로 진입 가능성을 검토할 수 있으나, PX 진입을 이유로 제품·제조사·가격 전략을 현재 단계에서 변경하지 않는다.

현재 우선순위는:

**제품 개발 → 실제 성능 검증 → 제조사 선정 → 일반 시장성 검증**이다.

PX는 제품이 검증된 이후 별도 채널 전략으로 검토한다.

---

## 11. 실제 Qualification 원칙

현재 Production Model은 **QUALIFIED 상태가 아니다.**

실제 제조·측정 데이터가 충분히 확보되기 전에는 Qualification을 주장하지 않는다.

실측 데이터는 다음을 만족해야 모델 학습/검증에 사용한다.

- 원료/배합 추적 가능
- 공정조건 기록
- QC SOP 완전성
- raw measurement 보존
- 데이터 독립성 및 split 명확성
- 서로 다른 조건의 데이터를 임의로 동일 데이터처럼 결합하지 않음

P001 이후 필요한 추가 실험 수는 실제 오차와 불확실성에 따라 결정한다.

---

## 12. 현재 하지 않는 것

현재 단계에서는 다음을 하지 않는다.

- P001~P018 전체 실제 제조
- 16~18개 물리실험을 미리 확정
- 제조사에 최종 Formula 생산만 요구
- 6개 업체 모두에 본격적인 신규 제형 개발비 지출
- 글로벌 규제 엔진 구축
- 자동 인증/안전 판정 시스템 구축
- 국가별 Formula 최적화 엔진 구축
- CPSR/PIF 등 규제 문서 자동생성 플랫폼 구축
- 제조사 최종 선정 전 대량 생산 확정
- 3,000개 최소 생산량 고정
- PX 입점을 현재 제품개발의 필수조건으로 설정

## 13. 현재 실행 순서

### Step 1
현재 코드와 문서를 본 실행계획과 대조한다.

### Step 2
6개 제조사에 1차 RFQ를 보낸다.

### Step 3
제조사의 제형개발 방식, 샘플 비용, MOQ, 일정, IP, 생산능력을 비교한다.

### Step 4
2~3개 기술 후보를 선정해 실제 샘플 개발을 진행한다.

### Step 5
동시에 P001의 원료 Grade/CoA, Formula, 제조조건, QC SOP를 확정한다.

### Step 6
P001 prediction snapshot을 실제 모델/코드 버전으로 생성하고 동결한다.

### Step 7
P001을 실제 제조·측정한다.

### Step 8
예측값과 실측값을 비교한다.

### Step 9
오차/불확실성/EIG를 다시 계산한다.

### Step 10
**두 번째 실제 실험이 필요한지 먼저 판단하고**, 필요한 경우에만 추가 실험을 실행한다.

### Step 11
제조사 샘플과 P001 및 이후 실험 결과를 분리된 데이터 계보로 관리하면서 최종 제품/제조 파트너/상업 생산량을 결정한다.

## 14. 문서 충돌 방지 규칙

앞으로 과거 계획과 현재 계획이 충돌할 경우 다음 순서를 따른다.

1. `docs/CURRENT_EXECUTION_PLAN_REV2.md`
2. 최신 날짜의 실행계획/의사결정 문서
3. 최신 `CHANGELOG`
4. 기존 `DEVELOPMENT_PLAN` 및 이전 Rev 문서

과거 문서는 역사적 기록으로 보존한다. 삭제하거나 현재 계획처럼 재사용하지 않는다.

새로운 핵심 결정이 생기면 먼저 이 문서 또는 별도의 versioned decision 문서를 업데이트한 뒤 코드 변경을 진행한다.

## 15. 최종 한 줄 기준선

**GLIDE는 제조사에 정해진 처방을 단순 생산시키는 브랜드가 아니라, 명확한 제품 목표를 제시하고 여러 제조사의 제형·공정 개발안을 비교한 뒤 실제 제조·측정 데이터와 GLIDE 시뮬레이션을 연결해 가장 좋은 제품을 선택하고 계속 개선하는 개발 시스템을 만든다.**
