# GLIDE-SPEC 40 Current Execution Plan Rev.2

작성일: 2026-09-14
상태: CURRENT / 실행 기준선

## 0. 이 문서의 우선순위

이 문서는 과거 DOE/Physical Pilot 계획과 현재 실행 결정을 구분하기 위한 **현재 실행 기준선**이다.

현재 계획과 과거 문서가 충돌할 경우, 이 문서를 우선한다. 과거 문서는 삭제하지 않고 변경 이력을 유지한다.

---

## 1. 핵심 개발 목표

GLIDE-SPEC 40의 현재 핵심 목표는 대규모 실험을 수행하는 것이 아니다.

**공개 데이터와 가상 시뮬레이션으로 후보를 최대한 좁힌 뒤, 실제 제조 실험을 최소화하고, 실제 측정값으로 모델을 검증·개선하는 것**이다.

기본 흐름:

```text
공개 데이터
   ↓
GLIDE Simulator / Virtual Screening
   ↓
후보 압축
   ↓
최소 실제 제조·측정
   ↓
예측값 vs 실측값
   ↓
오차 분석 / 모델 개선
   ↓
순차적 Active Learning
   ↓
필요한 경우에만 추가 실험
```

---

## 2. 실제 GLIDE 모델 검증 실험

### 현재 결정

**처음부터 P001~P018 전체를 제조하지 않는다.**

첫 번째 실제 검증은 **1개 후보만 제조**한다.

현재 첫 후보는 **GS40-P001**로 관리한다.

P001~P018은 가상 DOE/후보군 및 과거 DOE 설계상의 식별자로 유지할 수 있으나, 실제 제조 일정 또는 실제 Qualification 데이터셋을 의미하지 않는다.

### 중요한 구분

- P001~P018 = 후보/가상 DOE 공간
- 첫 실제 GLIDE 검증 = P001 1개
- 추가 실제 실험 = 첫 실측 결과와 모델 불확실성에 따라 결정
- 실제 Qualification의 최소 표본 수는 사전에 억지로 채우지 않고, 데이터 품질·독립성·모델 성능을 기준으로 판단

따라서 과거 문서에 있는 **“18-run batch manufacture”, “n ≥ 16 physical pilot”** 표현은 현재 실행계획으로 사용하지 않는다.

---

## 3. P002의 현재 지위

과거 Rev.8 계획에서는 EIG Ranker의 Top-1이 `GS40-P002`로 기록되어 있었다.

현재 실행 결정에서는 **P001을 첫 실제 검증 후보로 우선한다.**

따라서 P002의 과거 Top-1 EIG 기록은 삭제하지 않되, **현재 실행 순서를 결정하는 기준으로 사용하지 않는다.**

향후 P001 실측 결과가 확보되면 P001~P018 전체 후보의 EIG/불확실성을 다시 계산하여 다음 실험 후보를 결정한다.

---

## 4. 제조사 개발 트랙과 GLIDE 검증 트랙은 분리한다

제조사와 진행하는 샘플 개발 수와 GLIDE 모델의 독립 검증 실험 수는 같은 숫자가 아니다.

### 제조사 트랙

```text
6개 제조사 RFQ
   ↓
2~3개 기술 후보
   ↓
2~3개 제조사 샘플 개발
   ↓
사용자 비교 테스트
   ↓
처방/공정 수정
   ↓
파일럿
   ↓
첫 상업 생산 검토
```

제조사 샘플은 제품 개발을 위한 비교 자료이며, 측정조건과 데이터 독립성이 확보된 경우에만 GLIDE의 외부 검증 데이터로 활용한다.

### GLIDE 모델 트랙

```text
Virtual candidates
   ↓
P001 실제 제조/측정
   ↓
prediction vs actual
   ↓
model update
   ↓
next-best experiment 판단
```

**제조사 샘플 2~3개를 만든다는 사실이 GLIDE의 첫 검증 실험을 2~3개 또는 18개로 늘리는 것을 의미하지 않는다.**

## 5. Rev.7.3의 위치

Rev.7.3은 **개발 기준선(Target Active Formula)**이다.

최종 생산 Formula로 고정하지 않는다.

제조사와 실제 샘플을 개발할 때 목표 물성을 유지하면서 원료 Grade, 세부 배합비, 공정조건 등을 조정할 수 있다.

변경 시에는 반드시:

- 변경 항목
- 변경 이유
- 기대 효과
- 실제 결과
- 관련 Formula/Process/Data version

을 기록한다.

---

## 6. 제조사 실행의 현재 순서

현재 제조사 업무는 추가적인 업체 수집보다 **1차 RFQ 실행**을 우선한다.

1. MLS
2. 한국화장품제조
3. 모나미코스메틱
4. 라온하제
5. 헤이브랩
6. 코스모C&T

첫 문의에서는 전체 세부 처방을 공개하지 않는다.

확인할 핵심은:

- 20 g 전후 고형 스틱 제조 가능 여부
- 무수/oil/wax/silicone 계열 경험
- 미세 분말 분산 경험
- 유사 제형 실제 생산 사례
- 샘플 개발 가능 여부
- 500~1,000개 테스트 생산 가능 여부
- 내용물 MOQ와 패키지 MOQ 분리
- 개발비/샘플비/납기
- QC/안정성 시험 범위
- 처방 소유권/IP 조건

---

## 7. 초기 상업 생산량

**3,000개를 최소 생산량으로 고정하지 않는다.**

현재는 약 **1,000~3,000개** 범위에서 검토한다.

500개 생산이 기술적·경제적으로 가능한 제조사가 있으면 별도 검토할 수 있다.

첫 상업 생산량은 제조사 답변, 샘플 결과, 패키지 MOQ 및 견적을 확인한 뒤 결정한다.

2,950 KRW/unit은 목표 COGS이며 검증된 제조원가가 아니다.

---

## 8. 규제의 위치

규제는 별도의 대형 Regulatory Engine으로 만들지 않는다.

현재 단계에서는 formulation workflow에 최소한의 **Regulatory Pre-screen**만 둔다.

```text
원료/처방 후보
   ↓
Regulatory Pre-screen
   ↓
PASS / REVIEW / FAIL / UNKNOWN
   ↓
Simulator / 제조 후보 검토
```

최소 관리 항목:

- 금지/제한 원료
- 사용 한도
- 기능성화장품/특수 분류 가능성
- claim 근거 필요 여부
- 시장별 추가 검토 필요 여부

GLIDE가 최종적으로 안전·인증·법적 적합성을 자동 선언하지 않는다.

---

## 9. 실제 Qualification에 대한 원칙

현재 Production Model은 **QUALIFIED 상태가 아니다.**

실제 제조·측정 데이터가 확보되기 전에는 Qualification을 주장하지 않는다.

실측 데이터는 다음 조건을 만족해야 모델 학습/검증에 사용한다.

- 원료/배합 정보가 추적 가능
- 공정 조건이 기록됨
- QC SOP가 완전함
- raw measurement가 보존됨
- 독립성 및 data split이 명확함
- 동일한 SOP가 아닌 데이터를 임의로 합치지 않음

첫 실제 데이터가 확보된 뒤 필요한 추가 실험 수를 다시 판단한다.

---

## 10. 현재 하지 않는 것

현재 단계에서는 다음을 실행하지 않는다.

- P001~P018 전체 실제 제조
- 16~18개 물리실험을 미리 확정
- 글로벌 규제 엔진 구축
- 자동 인증/안전 판정 시스템 구축
- 국가별 Formula 최적화 엔진 구축
- CPSR/PIF 등 규제 문서 자동생성 플랫폼 구축
- 제조사 최종 선정 전 대량 생산 확정
- 3,000개 최소 생산량 고정

## 11. 다음 실행 순서

### Step 1
현재 코드와 문서를 이 Rev.2 기준과 대조한다.

### Step 2
P001 실제 검증을 위해 필요한 원료 Grade, Formula, 제조조건, QC SOP를 확정한다.

### Step 3
동시에 6개 제조사에 1차 RFQ를 보낸다.

### Step 4
제조사 2~3개 기술 후보의 샘플 개발 가능성을 비교한다.

### Step 5
P001의 실제 제조/측정을 실행한다.

### Step 6
예측값과 실측값을 비교하고 모델 업데이트 여부를 판단한다.

### Step 7
불확실성/EIG를 다시 계산하여 **두 번째 실제 실험이 필요한지부터 판단**한다.

### Step 8
필요한 만큼만 순차적으로 실제 실험을 추가한다.
