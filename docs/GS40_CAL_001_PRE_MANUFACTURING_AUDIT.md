### ④ Domain Adaptation 수학적 거동 특성
- **가우시안 RBF 커널 공간 수축 설계:**
  $$\hat{y}_{\text{adapted}}(x) = \hat{y}_{\text{prior}}(x) + w(x) \cdot (y_{\text{actual}} - \hat{y}_{\text{prior}})$$
  $$w(x) = \exp\left(-\frac{1}{2}\left(\frac{\|x - x_{\text{cal}}\|}{\ell}\right)^2\right), \quad \ell = 12.0$$
- **아키텍처 설계 특성 (실험적 성능이 아닌 수학적 속성):**
  - $x \approx x_{\text{cal}}$ (P001 인접 제형): $w \approx 1.0 \implies$ 잔차의 100% 반영, 모델 불확실성 최대 60% 축소.
  - $\|x - x_{\text{cal}}\| = 18.18$ (P008 직교 제형): $w = 0.317 \implies$ 전역 편향의 31.7%만 완만하게 반영되며, 81%의 불확실성이 유지되어 과도한 축소(Over-shrinkage) 방지.
- **현장 유의 사항:**
  - 위 거동은 수학적 수축 알고리즘의 동작 특성이며, 실제 물리적 제형에서 잔차가 공간적으로 이와 같이 전파되는지는 추후 다중 배치 측정을 통해 검증되어야 함.

### ⑤ 순차적 후보 선정 과정의 알고리즘 누수 방지
- **알고리즘적 누수 차단:** `recalibrate_candidate_runs()`는 이미 측정된 `GS40-P001`을 후보 리스트에서 원천 제외하고 나머지 17개 미실행 제형만 평가함.
- **다양성 인자:** 거리 인자 $(1 + 0.08 \ln(1 + \text{dist}))$를 곱하여, P001 근처의 중복된 제형(예: P012, 거리 6.23) 대신 직교 공간을 탐색하는 제형에 가중치를 부여함.
- **현장 유의 사항:**
  - 이는 코드 상의 샘플 제외 및 거리 가중 규칙을 의미하며, 실제 미지의 물리 제형에 대한 모델의 일반화 능력은 실측 데이터가 누적되기 전까지 미검증 상태임.

## 3. 완전한 단일 라인 Lineage 추적 체계 (End-to-End Lineage Chain)

`CAL-001` 제조의 진정한 가치는 단순 3개 숫자 획득이 아니라, 아래의 **단일 스레드 Lineage 추적성**을 확보하는 것입니다:

```text
[1. 원료 Lineage]
  ├── 실제 공급사(Supplier) 및 제품명(Trade Name / Grade)
  ├── 원료별 고유 Lot Number
  ├── 입고 CoA 검증 확인 (특히 MQ Resin의 실측 Solids % 및 캐리어 종류)
  └── 실제 정밀 계량치 (g, 감도 0.01g)
       │
       ▼
[2. 공정 Lineage]
  ├── 실제 교반 속도(RPM) 및 교반 시간(min)
  ├── 실제 용해 온도(Melt Temp) 및 충진 온도(Fill Temp)
  ├── 탈포 조건 (진공도 -0.08 MPa 유지 시간)
  ├── 냉각 프로파일 (챔버 온도 10°C, 냉각 속도 2.5°C/min, 45분 유지)
  └── 몰드 예열 온도(45°C) 및 탈형 코어 온도(20°C)
       │
       ▼
[3. 시편 및 보관 Lineage]
  ├── 스틱 몰드 번호 및 시편 고유 ID (CAL-001-S01 ~ S05)
  └── 항온/항습 챔버 조건 (25.0°C / 50% RH에서 24시간 숙성 이력)
       │
       ▼
[4. 원시 측정값 (Raw Replicates)]
  ├── Hardness: 5개 스틱 중앙부 원시 침투 저항치 (H1, H2, H3, H4, H5)
  ├── Transfer: BioSkin 인공피부 시트 도포 전/후 원시 차중 3회 (Δm1, Δm2, Δm3)
  └── Drop Point: 적점 셀 오리피스 최초 낙하 감지 온도 (°C)
       │
       ▼
[5. 최종 대표 응답 및 편향 산출]
  └── Mean & SD 산출 ➔ Residual = Actual - Prior 계산 ➔ 모델 보정 입력
```

## 4. 6단계 거버넌스 승격 사다리 (Qualification Progression)

CAL-001 단 1개 배치로 모델을 "Calibrated"라고 부르지 않으며, 아래의 엄격한 6단계 사다리를 따릅니다:

```text
1. [Prior Model] (N = 0, 현재 상태)
   └─ 공개 문헌 + 물리 기반 대리 모델 (실측 전 가상 목표 탐색)
        │
        ▼
2. [CAL-001 Domain Anchor] (N = 1, 제조 대기)
   └─ P001 단일 배치 제조 및 실측 (Hardness, Transfer, Drop Point)
        │
        ▼
3. [Residual Domain Adaptation] (N = 1)
   └─ Residual = Actual - Prior 계산 ➔ Empirical Bias 산출
        │
        ▼
4. [Adaptive Run #2 Selection] (N = 1 ➔ 2)
   └─ CAL-001 실측치 기반 P002~P018 전면 재평가 후 차기 최적 런 동적 선정 (P008 사전 예약 금지)
        │
        ▼
5. [Domain Adapted Model] (N = 2 ~ 15)
   └─ 순차적 능동 학습 배치 누적 및 공간적 불확실성 축소
        │
        ▼
6. [Production Qualification] (N >= 16)
   └─ Rev 2.0 Gatekeeper (Repeatability CV <= 4%, Lack-of-Fit p >= 0.05, Group-CV R² >= 0.85) 통과 후 양산 출시
```
