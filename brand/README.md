# GLIDE-SPEC 40 Brand Strategy

## Purpose

This directory contains the brand strategy and commercial product-planning layer built around GLIDE-SPEC 40.

The engineering/R&D repository remains the source of truth for formulation, testing, data, and technical implementation. This directory captures the customer, market, brand, and product decisions that should feed those technical requirements.

## Current strategic direction

- Origin insight: long-distance runners often use generic petroleum jelly such as Vaseline for friction protection.
- Strategic question: rather than adapting generic cosmetics to sport, what would skincare designed from the conditions of sport look like?
- Initial customer: marathon and ultra-distance runners.
- Initial category direction: endurance / performance skin care.
- Initial product direction: long-duration skin protection, with anti-chafe as a function rather than the entire brand category.
- Core development variables: TIME × MOTION × ENVIRONMENT.
- Long-term journey: PROTECT → PERFORM → RECOVER → OPTIMIZE.
