# Community Evidence Registry — v0.1

## Purpose

Community observations are treated as first-class hypothesis-generating evidence for brand strategy and product discovery.

Anecdotes must not be converted directly into universal product claims. Each observation should preserve the original context, product, body area, distance/duration, environment, outcome, and confidence.

## Evidence record template

| Field | Record |
|---|---|
| Source | URL / platform / thread |
| Date | publication date |
| Athlete context | runner type, distance, experience if available |
| Conditions | heat, humidity, rain, cold, duration |
| Body area | exact location |
| Product / solution | product or workaround used |
| Expected benefit | what the user wanted |
| Observed outcome | what actually happened |
| Failure point | when/where it failed |
| Reapplication | yes/no + timing |
| Positive signal | what users liked |
| Negative signal | what users disliked |
| Switching behavior | previous/current alternative |
| Evidence class | direct report / comparison / repeated pattern / expert interpretation |
| Confidence | low / medium / high |
| Strategic implication | hypothesis generated |

## Interpretation rules

1. One anecdote is a signal, not a market fact.
2. Repeated independent reports increase confidence but do not establish causal performance.
3. Positive and negative reports must both be retained.
4. Product failures should be recorded with conditions; "doesn't work" without context is incomplete.
5. Reapplication behavior is especially important because it reveals the user's real operating timeline.
6. Differences by body area must not be collapsed into one generic anti-chafe problem.
7. Contradictory reports are valuable: they may reveal user, environment, formulation, or application differences.
8. Community evidence should generate questions for controlled testing and user interviews.

## Priority research signals

The current research program should specifically capture reports about:

- long-duration persistence
- sweat and humidity
- rain / water exposure
- heat
- greasy feel or residue
- clothing transfer / staining
- stick versus balm versus petroleum jelly application
- reapplication during marathon and ultra events
- body-area-specific differences
- combinations with tape or clothing/equipment changes
- reasons athletes continue using an imperfect incumbent solution

## Evidence ledger

No individual community post is entered here unless its source and context are preserved. The registry should be populated during the next dedicated community-research pass.
