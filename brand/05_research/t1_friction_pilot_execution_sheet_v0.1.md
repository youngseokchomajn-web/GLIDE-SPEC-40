# GLIDE-SPEC 40 T1 Friction Pilot — Execution Sheet v0.1

Date: 2026-09-13
Status: Execution worksheet; method-development only

## 1. Objective

Execute the T1 pilot without prematurely converting laboratory friction data into a consumer-performance claim.

Primary questions:

1. Is the measurement repeatable?
2. Can untreated control be distinguished from incumbent products?
3. Does controlled moisture change the measured result?
4. Is the method stable enough for GLIDE-SPEC candidate comparison?

## 2. Required test set

### Phase A — Control

- untreated interface
- repeated measurements
- same surrogate, textile, load, speed and environmental condition

### Phase B — Incumbents

- petrolatum
- specialized anti-chafe stick
- specialized balm/ointment

### Phase C — Moisture

Repeat the stable control/incumbent configuration under the defined sweat-simulated condition.

GLIDE-SPEC candidate formulations are not required for Phase A/B method qualification.

## 5. Required raw outputs

For every valid run retain:

- raw force trace where available;
- individual friction values;
- cycle/time point;
- product code;
- specimen ID;
- application mass and area;
- environmental conditions;
- instrument settings;
- operator;
- deviations;
- visible migration/transfer observations.

## 6. Immediate QC checks

After each measurement block ask:

### Control stability

- Did untreated measurements drift materially?
- Did specimen condition change?
- Was textile mounting stable?

### Signal quality

- Did force remain within instrument range?
- Was the trace physically plausible?
- Was there slip, sticking, pooling or sudden saturation?

### Application consistency

- Was mass/area within the predefined method window?
- Was waiting time consistent?

### Moisture consistency

- Was moisture loading reproducible?
- Did pooling or uncontrolled wet slip occur?

If not, mark the run as a deviation and diagnose before ranking products.

## 7. Analysis outputs

Produce separately:

1. untreated repeatability;
2. incumbent-vs-control effect;
3. within-day variance;
4. between-day variance;
5. cycle-dependent trajectory;
6. dry-vs-moist change;
7. visible film/migration observations;
8. anomalous-run log.

Do not collapse these into a single product score.

## 8. Pilot decision matrix

| Finding | Decision |
|---|---|
| Control unstable | Modify method; repeat control phase |
| Control stable, incumbents indistinguishable | Diagnose sensitivity/range; modify method |
| Control stable, incumbent differences reproducible | Proceed to moisture phase |
| Moisture condition unstable | Redesign moisture application |
| Moisture condition stable and informative | Lock T1 configuration for incumbent baseline |
| Candidate prototypes available only after method lock | Begin matched candidate comparison |

## 9. Minimum evidence package before candidate testing

The following must exist before GLIDE-SPEC candidate comparison begins:

- locked surrogate/textile specification;
- locked application normalization method;
- locked motion settings;
- locked environmental condition;
- locked moisture protocol if applicable;
- replicate structure justified by pilot variance;
- untreated control baseline;
- incumbent baseline;
- raw-data schema;
- deviation log;
- method decision memo.

## 10. Evidence linkage

Every material conclusion must link back to:

`technical failure mode → evidence ID → test ID → raw measurement → interpretation → next test`

A laboratory result without this chain is not sufficient to change the GLIDE-SPEC product requirement.

## 11. Prohibited conclusions at T1

Do not report:

- “lasts X hours”;
- “prevents chafing”;
- “clinically proven”;
- “better than Vaseline”;
- “best anti-chafe product”;
- universal anatomical suitability;
- final consumer dosage;
- final formulation choice.

T1 is a method and comparative bench-evidence stage, not a finished-product claim study.
