# Price / Value Research Protocol — v0.1

Date: 2026-09-13

## Objective

Estimate the price range Korean endurance runners perceive as credible and acceptable for a purpose-built endurance skin-protection product, while separating stated willingness-to-pay from observed spending and product trade-offs.

## Why a single “How much would you pay?” question is insufficient

Direct WTP questions can be biased by hypothetical response behavior. Van Westendorp is useful for early-stage acceptable-price range estimation, while choice-based methods are better suited to understanding trade-offs among price, features, and alternatives. cite-source-placeholder

Therefore this study uses three layers.

## Layer 1 — Actual category economics

For each respondent collect:

- current product(s)
- package size
- purchase price
- purchase frequency
- approximate annual spend
- whether bought domestically or imported
- shipping/import premium if relevant
- whether tape, garments, or equipment changes are used instead
- approximate annual spend on those substitutes when known

Primary question:

> “지금 이 문제를 해결하기 위해 실제로 1년에 얼마 정도 쓰고 있는가?”

This is more decision-useful than hypothetical WTP alone.

## Layer 2 — Van Westendorp-style price sensitivity

Show one standardized concept card before asking price questions.

Concept card must specify:
- intended use
- package size
- format
- key validated-or-hypothetical benefits clearly labeled
- no invented performance number
- no premium-brand prestige framing

Four questions:

1. **Too cheap:** “이 제품이 얼마 이하이면 너무 저렴해서 품질이 좋지 않을 것 같다고 느끼시나요?”
2. **Good value:** “얼마이면 가격 대비 매우 좋은 제품이라고 느끼시나요?”
3. **Getting expensive:** “얼마부터 비싸다고 느끼지만 그래도 구매를 고민해볼 수 있나요?”
4. **Too expensive:** “얼마이면 너무 비싸서 구매하지 않겠다고 생각하시나요?”

Analyze the resulting price-threshold distributions by runner segment.

Do not call the resulting intersection an “optimal market price” without qualification. It is a psychological price-range diagnostic, not a guaranteed demand or profit optimum. cite-source-placeholder

## Layer 3 — Choice trade-off

Present randomized purchase choices containing:

| Attribute | Example levels for research only |
|---|---|
| Protection/persistence | basic / enhanced / very long-duration claim only after validation |
| Sweat/water behavior | basic / sweat-focused / sweat+water |
| Format | stick / balm / roll-on |
| Application | easy / very easy + reapplication-oriented |
| Skin compatibility | standard / sensitive-skin-oriented |
| Carry | home-use / compact race-carry |
| Price | multiple realistic levels derived from actual category prices + PSM |

Each choice set should include a “none / keep current solution” option.

The purpose is to determine whether respondents actually trade price for performance and convenience, rather than claiming that every attribute is important.

## Segment outputs

Report price/value separately for:

1. marathon/ultra runners
2. half-marathon runners
3. runners with recurrent chafing
4. runners with occasional/no chafing
5. users of petroleum jelly
6. users of specialized anti-chafe
7. users who switch to tape/garment/equipment solutions
8. users with relevant skin-sensitivity concerns

Do not average these groups into a single “runner price.”

## Decision outputs

The research should produce:

- observed current spend band
- acceptable psychological price range
- price rejection threshold
- purchase-intent curve at selected prices
- feature/price trade-off
- substitution threshold versus current solution
- reasons for paying more
- reasons for refusing to pay more

## Price decision rule

No final launch price should be selected from this study alone.

A launch price should require:

1. actual manufacturing cost and MOQ economics;
2. packaging and distribution costs;
3. competitor price/size normalization;
4. observed user value and switching behavior;
5. prototype performance relative to incumbents;
6. channel margin requirements.

## Important research boundary

Price sensitivity is not evidence of product efficacy. A high stated WTP does not validate a performance claim, and a low WTP does not prove that the problem lacks importance.
