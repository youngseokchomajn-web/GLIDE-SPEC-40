# Global Expansion — v0.1

## Beachhead

Start with endurance running because the problem is concrete, the use case is observable, and the user journey can be mapped from preparation through recovery.

## Expansion logic

Expand by shared skin-stress mechanisms rather than by arbitrary sport categories.

Potential sequence:

1. Marathon
2. Ultra / trail running
3. Cycling
4. Triathlon
5. Hiking / outdoor endurance
6. Other prolonged-motion activities

## Global brand hypothesis

The brand can originate from Korean formulation and R&D capabilities while defining the consumer category around a globally understandable human problem: skin under prolonged movement.

This avoids relying solely on the label "K-beauty" as the core differentiator.

## Expansion rule

A new sport should enter the portfolio only when its skin-stress profile produces a meaningful product requirement that can be connected to the brand's existing scientific framework.

Status: strategic hypothesis.
